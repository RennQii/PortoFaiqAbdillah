# Faiq Abdillah — Orbit Portfolio Prototype

## Menjalankan
1. Ekstrak folder/ZIP.
2. Pastikan `index.html`, `style.css`, dan `script.js` berada dalam folder yang sama.
3. Buka `index.html` di browser.

Tidak perlu instalasi atau build tools. Koneksi internet hanya dibutuhkan untuk memuat Google Fonts.

## Mengubah konten
- Nama, headline, dan teks halaman awal: edit `index.html`.
- Warna, ukuran, posisi orbit, dan responsive layout: edit `style.css`.
- Isi masing-masing bagian navigasi: edit object `sections` di `script.js`.
- Foto profil: ganti blok `.avatar` di `index.html` dengan elemen `<img>` dan sesuaikan CSS.

## Catatan
Konten pendidikan, pengalaman, proyek, pencapaian, email, dan tautan sosial sengaja berupa placeholder agar tidak mengarang informasi. Ganti dengan data final sebelum dipublikasikan.
